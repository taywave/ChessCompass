# Chess Compass Landing Page

Static, mobile-first landing page for the free Chess Compass Improvement Checklist.

## Files

- `index.html` - complete landing page
- `styles.css` - responsive styling and brand system
- `script.js` - temporary form behavior
- `assets/CCBackground.png` - supplied Chess Compass background
- `assets/Chess-Compass-King-Logo-transparent.png` - supplied logo with white background removed

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `chess-compass`.
2. Upload all files while preserving the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save. GitHub will provide the public URL.

## Important: email form

The current form is intentionally a front-end placeholder. It does not send email.

Before launch, replace the `action="#"` form behavior with your chosen email/form provider. The page does not need a paid backend or custom server.
